# 2D-platformer

2D Platformer

A small pixel-art platformer where you run, jump, and collect coins through a hand-built level. Watch out for spikes and patrolling slimes, and don't fall off the map!

Made for Hack Club Phantom. Right now it has one finished level, with more on the way.

Controls
Key	Action
Left / Right arrows	Move
Space (or Enter)	Jump

Click the game once so it captures your keyboard.

How to play
Press Start on the main menu.
Collect coins. Your score shows at the top of the screen.
Spikes and slimes send you back to the start of the level.
Falling off the map restarts the level too.
Features
Main menu with a Start button
Player movement and jumping
Collectible coins with a score counter
Spikes that reset the level
Slimes that patrol back and forth
A tilemap-based level with a scenic background

Run it yourself
Download and install Godot 4.7 (the standard version, not .NET).
Clone this repo:
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
Open Godot, click Import, and select the project.godot file in the cloned folder.
Open the project, then press F5 (or the Play button in the top right) to run it.
Exporting for the web (optional)
In Godot, go to Project > Export and add a Web preset (install the export templates if Godot asks).
Set the export path to index.html and click Export Project.
Zip the exported files so index.html is at the top level, then upload that zip to itch.io as an HTML project.
